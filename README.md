# Tremis-tremida-
um aplicativo de desenho com a função de wiggle, aqui voce pode usar ele para fazer desenhos com o efeito tremido podendo exportar para gif, 

atalhos:
ctl z - desfazer
e - borracha
b - pincel

voce tambem pode alterar a frequencia e a o nivel das tremidas
